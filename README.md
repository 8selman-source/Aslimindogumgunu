# ASLI — 20. Yaş Günü

GitHub deposuna bu klasörün **içindeki dosyaları** yükleyin. Render → New → Web Service → repo seçin. Build Command: `npm install`; Start Command: `npm start`. `render.yaml` da dahildir.

İçerik `content.json` dosyasındadır. Görseller `assets` içindedir. Eksik fotoğraflar için başka görsel uydurulmamıştır. Video ve müzik dosyaları sağlanmadığından oynatılmaz.

Yerel: `npm start`, ardından `http://localhost:3000`.
